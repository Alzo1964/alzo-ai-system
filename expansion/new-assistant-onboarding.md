# New Assistant Onboarding

## Purpose

New assistant onboarding defines how ALZO AI System assistants such as Nova should be introduced without creating overlap or confusion.

## Onboarding Steps

1. Define the assistant name and purpose.
2. Document the assistant's responsibilities and limits.
3. Identify which studio or system layer the assistant supports.
4. Define communication style and output structure.
5. Add routing rules for when the assistant should be used.
6. Review overlap with Vera, Mira, and existing studios.

## Nova Example

Nova may become a future specialized assistant layer for research, market intelligence, finance, legal review, or another focused operating domain.

## Modularity Rules

Each assistant should remain independently understandable, reusable, and replaceable without disrupting the rest of the system.
