# Studio Separation Rules

## Purpose

Studio separation rules define how a studio can later become its own system while preserving alignment with the ALZO AI System.

## Separation Criteria

A studio may be separated when it has:

- A distinct operating model.
- Dedicated workflows and templates.
- Independent reporting needs.
- Clear ownership and routing rules.
- Enough activity to justify a standalone system.

## Separation Process

- Preserve the original studio history.
- Move only domain-specific files into the new system.
- Keep shared standards documented at the ALZO system level.
- Maintain clear links between the parent system and separated studio.

## Modular Rules

Separated studios should keep compatible naming, documentation, reporting, and backup patterns wherever possible.
