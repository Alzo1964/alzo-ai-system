# Workflow Automation

## Purpose

Workflow automation supports repeatable movement of work through intake, routing, execution, review, and completion.

## Vera Automation Role

Vera should use workflow automation to classify requests, assign studios, identify dependencies, track blockers, and prepare review-ready outputs.

## Workflow Structure

A workflow should define:

- Input source.
- Assigned role or studio.
- Current status.
- Required actions.
- Dependencies.
- Review checkpoint.
- Completion criteria.

## Status Tracking

Recommended workflow states include `new`, `classified`, `routed`, `in-progress`, `blocked`, `awaiting-review`, and `complete`.

## Future API Integrations

Future versions may connect workflows to task systems, dashboards, memory records, databases, notification services, and external automation platforms.
