# Vera Dashboard

## Purpose

The Vera dashboard is the executive view for system-level clarity, decision support, and operational routing across the ALZO AI System.

## Executive View

The view should briefly show:

- Active strategic priorities.
- Current studio work.
- Open decisions.
- Risks, blockers, and dependencies.
The Vera dashboard is the executive operating view for the ALZO AI System. It should help Vera review priorities, route work, monitor risks, and maintain system-level clarity.

## Executive View

The view should include:

- Current strategic priorities.
- Active studio work.
- Key decisions awaiting review.
- Open risks, blockers, and dependencies.
- Recent reports or system updates.

## Status Tracking

Vera should track work with clear states: `planned`, `in-progress`, `blocked`, `awaiting-review`, `complete`, and `archived`.

## Future UI Direction

Future versions may add executive summaries, studio health indicators, decision timelines, workflow status, and links to memory records.
Vera should be able to see whether work is planned, active, blocked, awaiting review, or complete.

## Future UI Direction

Future versions may include decision timelines, studio health indicators, workflow automation status, and executive summaries generated from task and memory data.
