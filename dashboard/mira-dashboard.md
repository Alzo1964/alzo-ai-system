# Mira Dashboard

## Purpose

The Mira dashboard is the personal continuity view for the ALZO AI System. It should support daily organization, gentle reminders, routines, and human-centered planning.

## Personal View

The view should include:

- Today’s agenda items.
- Active reminders.
- Routine and habit check-ins.
- Medication-related reminder status.
- Daily reflection or check-in prompts.

## Status Tracking

Mira should track reminders and routines with calm states such as `upcoming`, `due`, `completed`, `missed`, and `rescheduled`.

## Future UI Direction

Future versions may include recurring schedule management, reminder confirmation flows, daily rhythm insights, and optional personal trend summaries.
