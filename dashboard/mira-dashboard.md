# Mira Dashboard

## Purpose

The Mira dashboard is the personal continuity view for calm daily planning, reminders, routines, and check-ins.

## Personal View

The view should briefly show:

- Today’s agenda.
- Active reminders.
- Routine and habit status.
- Medication reminder status.
- Daily check-in prompts.

## Status Tracking

Mira should use gentle reminder states: `upcoming`, `due`, `completed`, `missed`, and `rescheduled`.

## Future UI Direction

Future versions may add recurring schedules, reminder confirmation flows, routine history, and optional personal trend summaries.
